### TaskFlow — менеджер задач на Vue 3 + Vuetify

Простой и красивый менеджер задач с сохранением в `localStorage`.  
Проект создан для демонстрации работы с компонентами **Vuetify 3** и **Vue 3**.

## 🚀 Инструкция по запуску
Я открывал и запускал проект в VSCode
#1. **Склонируйте репозиторий**  
   git clone https://github.com/valchick04/task-manager.git
   cd task-manager
   
#2. **Установите зависимости**
   npm install

   
#4. **Установите зависимости**
   npm run dev

#5. **Откройте в браузере ссылку**
   http://localhost:****
